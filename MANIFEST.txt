ROOT LEVEL
----------

README.md                   Dokumentasi lengkap: instalasi, penggunaan, troubleshooting.
TESTING_CHECKLIST.md        12 test case untuk verifikasi di server cPanel.
MANIFEST.txt               File ini — daftar struktur project.

CONFIG/
-------
database.php               Konfigurasi koneksi MySQL/MariaDB. Edit sesuai data hosting cPanel Anda.

INCLUDES/ (Library & Helpers)
------------------------------
header.php                 Template navbar & doctype HTML global.
footer.php                 Closing HTML & script global.
functions.php              Fungsi bantu: e() sanitasi, rupiah() format, base_url(), upload foto, flash message, CSRF.
auth.php                   Sistem autentikasi: current_user(), require_login(), require_role(), attempt_login().
barcode128.php             Encoder CODE128 native PHP murni (tanpa dependency). Output SVG vektor untuk print tajam.
xlsx_lite.php              Pembaca/penulis file .xlsx (.csv juga support). Native PHP tanpa Composer/PhpSpreadsheet.
sparepart_repo.php         Repository/DAO — semua query database (search, filter, CRUD, riwayat cetak).

MODULES/ (Feature Modules)
---------------------------
auth/
  login.php                Halaman login. Default user: admin / admin123 (WAJIB UBAH).
  logout.php               Hapus session & redirect ke login.

sparepart/
  list.php                 Katalog marketplace grid. Search, filter, pagination. 4-6 kartu per baris (responsive).
  form.php                 Form tambah/edit sparepart. Validasi kode unik, upload foto.
  save.php                 Handler submit form. Simpan ke database, cek duplikat, upload foto aman.
  detail.php               Halaman detail sparepart. Foto besar, info lengkap, tombol cetak cepat, riwayat.
  delete.php               Soft delete sparepart (hanya admin).

barcode/
  generate.php             Generator barcode: pilih jumlah cetak, preview, print. Simpan riwayat cetak.
  bulk_print.php           Cetak massal: pilih beberapa sparepart sekaligus, tentukan jumlah masing-masing.
  history.php              Riwayat cetak barcode (semua sparepart). Tombol "Cetak Ulang".

scan/
  scan.php                 Halaman scan barcode via scanner USB (HID keyboard). Input auto-focus.
  scan_ajax.php            Endpoint AJAX pencarian sparepart by kode_custom. Respons JSON.

excel/
  template.php             Download template Excel (header + 1 contoh baris).
  import.php               Halaman import Excel/CSV. Validasi, handling duplikat (skip/update/cancel).
  export.php               Download Excel: semua sparepart (atau sesuai filter search).

ASSETS/

css/

js/

img/

SECURITY NOTES:
================
✓ PDO prepared statements — SQL injection protection
✓ htmlspecialchars() + e() helper — XSS protection
✓ CSRF token validation — form submission protection
✓ Password bcrypt hashing — password_hash() / password_verify()
✓ File upload validation — MIME type check, size limit, random rename
✓ Session-based auth — tidak ada cookie plaintext
✓ Role-based access — admin vs staff

DATABASE TABLES (auto-created via database.sql):
=================================================
users
  - id (PK)
  - username (UNIQUE)
  - password_hash (bcrypt)
  - nama_lengkap
  - role (enum: admin, staff)
  - is_active
  - created_at, updated_at
  Index: uq_username

spareparts
  - id (PK)
  - kode_custom (UNIQUE, INDEX) ← key untuk barcode
  - nama_sparepart (FULLTEXT)
  - foto (VARCHAR, path relatif ke uploads/)
  - merk, jenis_motor, kategori, satuan (INDEX)
  - harga_beli, harga_jual (DECIMAL 12,2)
  - stok (INT)
  - lokasi_rak, keterangan
  - is_active (soft delete flag)
  - created_at, updated_at
  Indexes: uq_kode_custom, idx_nama, idx_merk, idx_jenis_motor, idx_kategori

sparepart_foto_tambahan
  - id (PK)
  - sparepart_id (FK) → spareparts.id
  - path_foto
  - created_at

barcode_print_history
  - id (PK)
  - sparepart_id (FK) → spareparts.id
  - kode_custom (snapshot, karena nama bisa berubah)
  - nama_sparepart_snapshot
  - jumlah (berapa label dicetak)
  - printed_by (nama user)
  - printed_at
  Indexes: idx_sparepart_id, idx_kode_custom

KNOWN ISSUES & LIMITATIONS:
============================
1. Hanya 1 admin default (belum ada UI create user baru)
2. Tidak ada change password UI (edit manual di phpMyAdmin atau coding)
3. Print barcode hanya HTML5 print (tidak ada PDF backend generation)
4. Import Excel tidak support .xls lama/biner (hanya .xlsx & .csv)
5. Scanner USB hanya support HID keyboard mode (emulate keyboard, bukan serial/USB CDC)
6. No multi-language support (hanya Bahasa Indonesia)

INTEGRATION WITH SIMBENG:
===========================
Aplikasi ini didesain standalone. Jika mau integrasikan ke SIMBENG:

1. Analisa tabel sparepart SIMBENG (struktur, kolom, relasi)
2. Identifikasi mana yang bisa reuse, mana yang butuh kolom baru:
   - Tambah kolom: kode_custom, foto, lokasi_rak, kategori
   - Reuse kolom: nama_sparepart, harga_jual, stok, dll
3. Modify includes/sparepart_repo.php:
   - Change query SELECT dari tabel SIMBENG sparepart
   - Adjust WHERE clause & foreign key sesuai struktur SIMBENG
4. Change config/database.php:
   - Gunakan database yang sama seperti SIMBENG
   - User & privilege sudah ada
5. Test semua CRUD & barcode flow

Untuk integrasi detail, hubungi developer yang membuat aplikasi ini.
